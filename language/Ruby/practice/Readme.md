## 環境構築
**Ruby インストール**
```markdown
[Rudy download](https://rubyinstaller.org/)
```
注意：必ずadd path で環境変数内にRubyのbinファイルを挿入する。

### Rails 導入
```
gem install boundler # バージョン管理
gem install rails # rubyのフレームワーク
```
### VSCode 拡張機能
**Ruby LSP**
Rubyの予測変換 Rubyコードに色を適応する

**Ruby and Rails Snippets**
Railsのタブ補完

**irbについて**
Ruby を1行ずつその場で実行できる「対話型実行環境」
**学習において irb が有用な理由**
「読む」→「試す」が超速い
