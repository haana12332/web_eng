# 気づき
---
#### Rubyでの表示
**puts** : 整理された表示

* ユーザーへのメッセージ
* CLIAPP

**p**: 実際にRubyが所持しているデータを表示
* デバック用

---

**NULL = NIL で空を表す**

**Case文**
when には範囲オブジェクトを書くのが一般的（問5）

**繰り返し処理の使い分け**
**while:** 条件が成り立つ間、繰り返したい
**each:** 配列などの要素を順番に処理したい


#### **シンボル ＝ 定数**
任意の文字列と一対一に対応するシンボルクラスのオブジェクト
シンボルは内部で整数として管理されるため、同値なら必ず同一となる
