
# hash & list 問題
### 問題1：配列の合計値
問題

以下の配列があります。

numbers = [10, 20, 30, 40, 50]

each を使って合計値を計算してください。
```
出力例
合計は150です
```
### 問題2：配列から偶数だけ表示
問題

以下の配列があります。

numbers = [1, 2, 3, 4, 5, 6]

偶数だけを表示してください。
```
出力例
2
4
6
```
### 問題3：Hashから情報を取り出す
問題

以下の Hash があります。

user = {
  name: "Hotaka",
  age: 22,
  country: "Japan"
}

以下の形式で表示してください。
```
出力例
名前: Hotaka
年齢: 22
国: Japan
```
### 問題4：配列の中のHashを扱う
問題

以下の配列があります。

users = [
  { name: "Taro", age: 20 },
  { name: "Hanako", age: 25 },
  { name: "Ken", age: 18 }
]

each を使って、全員の名前と年齢を表示してください。
```
出力例
Taro : 20歳
Hanako : 25歳
Ken : 18歳
```
### 問題5：簡単な商品管理
問題

以下の商品データがあります。

products = [
  { name: "Apple", price: 120 },
  { name: "Banana", price: 100 },
  { name: "Orange", price: 150 }
]
商品名と値段を表示してください
全商品の合計金額を表示してください
```
出力例
Apple : 120円
Banana : 100円
Orange : 150円
```
合計金額は370円です
**この5問で学べること**
```
配列の基本操作
each の使い方
Hash の取り出し
配列 + Hash の組み合わせ
合計計算
条件分岐との組み合わせ
```
